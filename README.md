# systemTec


Sistema web para gestão de chamados técnicos, cadastro de profissionais com geolocalização (cálculo de distância em KM) e exportação de relatórios em CSV.

## Tecnologias Utilizadas
* **HTML5 & Bootstrap 5** (Interface responsiva)
* **JavaScript (Vanilla)** (Lógica e requisições)
* **Supabase / PostgreSQL + PostGIS** (Banco de dados e geolocalização)
* **OpenStreetMap (Nominatim)** (Geocodificação gratuita de endereços)
